# Prerequisites

## Lecture Summary

Understanding Prerequisites for GSAP Course

In this course introduction, the instructor outlines the basic prerequisites needed for successful participation, emphasizing the importance of a solid understanding of JavaScript fundamentals. The course keeps examples simple and framework-agnostic so students can effectively apply GSAP with their project or framework of choice.

## Key Takeaways

- A solid understanding of JavaScript fundamentals is required to take this course.
- If JavaScript skills are lacking, students can refer to the Path to JavaScript Mastery course to get up to speed.
- Examples are intentionally straightforward and framework-agnostic (HTML for structure, CSS for styling, and JavaScript/GSAP for animations).
- GSAP code learned can be adapted to frameworks like React, Vue, or Angular; only framework syntax differs.
- Toward the end of the course there will be a demonstration of integrating GSAP with a framework such as React.
